# Kargul craft bar — studio UI density (encode only)

Source (public): [kargul.studio](https://kargul.studio) · [@marcelkargul](https://x.com/marcelkargul) · studio stack posts (Figma / Rive / Next.js).

This recipe **encodes the operating patterns** behind their X portfolio flexes. Complementary look notes — **not** a second factory OS, **not** a hire brief, and **not** Autopilot unlock.

## Thesis

Great SaaS UI on X is usually **senior Figma craft + selective motion + senior implementation**, not a component zoo. Steal the bar; do not copy their clients' products.

## When to invoke

| Use | Skip |
|-----|------|
| Raising product chrome / dashboard density on ui:yes work | Every landing page (use Elaya / adjacent-taste landing rules) |
| Deciding whether a screen needs illustration or Rive | Greening TRUST-NEXT / overnight |
| Reviewing AI-generated UI for "studio" quality | Replacing Walter as frontend authority |
| Picking motion budget (hero only vs everywhere) | Vendoring their client mockups into Glass |

Owner for product application: **Walter** (ui:yes). Kitchen only encodes.

## Steal (encode these)

| Pattern | What it is | Where it lands | When |
|---------|------------|----------------|------|
| **Craft density** | Hierarchy, spacing, custom chrome, one idea per screen | Control-Glass / pack-shelf chrome; Walter direction | Before shipping a surface |
| **Figma → code** | Pixel product UI designed first; engineers implement | Feature Map slices; Design Mode | New UI units |
| **Hero motion only** | Rive / AE / Lottie on a few moments; not animation soup | Landing + key product moments; settigation MOTION.md still law | When motion earns attention |
| **Senior polish after AI** | Figma MCP / codegen allowed for speed; humans deslop | Tony build + Walter taste + Stewie anti-ai-ui | Any AI-assisted UI |
| **Portfolio ≠ product** | X quote-chains are marketing specimens | Do not treat posts as Feature Map | Intake from social |
