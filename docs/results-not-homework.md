# Results not homework (default)

Default exit check for every non-trivial ask across factory lanes.
Agents apply on close. Typing `/results-not-homework` is optional; the
skill in `cursor-team-kit` names the contract. Same shape as one-shot-task.

## Route

1. Before you stop, leave a mergeable artifact: open PR, brief,
   scorecard, or verified claim with evidence.
2. Never end with a "you should…" homework list for the human.
3. If something is blocked, say what is blocked and what artifact
   already exists. Do not dump a chore list.

## Autopilot stays off

Leave Autopilot and TRUST-NEXT off unless Dark has already greened them
with evidence. Do not invent Autopilot. Do not self-merge.
