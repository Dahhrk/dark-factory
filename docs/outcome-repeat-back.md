# Outcome repeat-back (default)

Default preamble for every non-trivial ask across factory lanes. Agents
start here automatically. Typing `/outcome-repeat-back` is optional; the
skill in `cursor-team-kit` names the contract. Same shape as one-shot-task.

## Route

1. Restate **Goal**, **Constraints**, **Done means**, and **Keep** in
   plain words before any encode or research fan-out.
2. Confirm the restatement matches the ask. Cut dump-to-wrong-build.
3. Then act under the one-shot route.

## Fail closed

Do not invent Done means when language gates are missing. Run
factory-init (then seat-kit) so gates exist, then derive the predicate
from them.

## Autopilot stays off

Leave Autopilot and TRUST-NEXT off unless Dark has already greened them
with evidence. Do not invent Autopilot. Do not self-merge.
