# Teach to skill (default)

Default post-pass across factory lanes. Agents apply after a pass.
Typing `/teach-to-skill` is optional; the skill in `cursor-team-kit`
names the contract. Same shape as one-shot-task.

## Route

1. After a pass, check whether the same manual flow recurred twice.
2. If yes, offer skill-authoring / learn-from-demonstration once.
3. Drop the offer if declined. Do not nag. Do not invent a skill
   shopping list.

## Autopilot stays off

Leave Autopilot and TRUST-NEXT off unless Dark has already greened them
with evidence. Do not invent Autopilot. Do not self-merge.
