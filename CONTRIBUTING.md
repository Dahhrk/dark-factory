# Contributing

This repo is a **kitchen** (docs, templates, automations drafts) — not a product app.

## Before you open a PR

1. Read [VISIBILITY.md](VISIBILITY.md) — no secrets, no real product Feature Maps.
2. Prefer small PRs; Conventional Commits (`docs: …`, `chore: …`, `feat(templates): …`).
3. Done means something checkable (link, script output, or a doc section that can be wrong).

## Local

```text
/poteto-mode …
Done means …
Keep kitchen stays kitchen; do not add a product app here.
```

Product verify/CI belongs in private app repos. Bootstrap: `templates/product-bootstrap/` or `scripts/new-product.ps1`.
