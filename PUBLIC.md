# How public vs private works

Modeled on Lauren's (@poteto) **actual** split. Full table: [docs/her-system-map.md](docs/her-system-map.md). Naming: [docs/naming.md](docs/naming.md).

```text
PUBLIC OS        →  pstack + cursor-team-kit   (Cursor marketplace)
PUBLIC TEACHING  →  this repo (dark-factory)   (docs / templates / examples)
PRIVATE FACTORY  →  ~/Projects/Control-Glass  (app + control-glass + Dune + CI)
```

| Want | Do |
|------|-----|
| Same tools she uses | `/add-plugin pstack` + `cursor-team-kit` |
| Read / share the recreate path | Use **this** repo |
| Run a trusted agent factory | Work in **Control-Glass** (private remote) |
| Contribute to other OSS | Open **their** repo; `/poteto-mode` + their CI |

Borrowed names stay **hers**: `/poteto-mode`, Feature Map, **Dune**, Benny, `control-<app>`, Autopilot.
